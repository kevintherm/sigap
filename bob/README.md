# bob/

Panduan untuk memakai IBM Bob (atau agen AI lain) dengan Sigap lewat MCP.

- `agent-instructions.md`: aturan yang sebaiknya diikuti agen saat memakai alat Sigap, misalnya selalu meminta persetujuan mahasiswa sebelum membuat pengingat atau meneruskan pertanyaan ke staf.
- `mcp_settings.example.json`: contoh pengaturan MCP. Ganti tokennya dengan token pribadi dari portal mahasiswa atau perintah `/token` di bot.

Token bertindak atas nama mahasiswa pemiliknya, jadi jangan dibagikan. Token bisa dicabut kapan saja dari portal mahasiswa.
