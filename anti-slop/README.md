# anti-slop/

Hasil audit tampilan web Sigap dengan aturan antislop, supaya tampilannya terasa dirancang dengan sengaja, bukan hasil cetakan AI.

- `audit-001-...`: audit pertama atas panel admin dan portal mahasiswa.
- `audit-002-...`: audit kedua khusus panel admin setelah ganti desain, beserta laporan perbaikannya (`...-fixes.md`).

Setiap temuan menyebut aturan yang dilanggar, tingkat kepentingannya, dan cara memperbaikinya. Panduan desainnya sendiri ada di `DESIGN.md` di folder utama.
